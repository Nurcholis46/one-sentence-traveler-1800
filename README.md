One sentence, at most 200 characters, explaining the modern internet to a time traveler arriving from the year 1800 — built only from things a person from 1800 already knows: a road, a library, a post office, a letter.

> Picture a road joining every library and post office on earth, so a letter written in one town can be read in another before its ink dries.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt`.
